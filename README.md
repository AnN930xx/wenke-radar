## 一、这是什么

一个跑在 GitHub 上的小工具。它每天早上替你把 45 个招聘官网刷一遍，
挑出**今天新放出的、你能投的**岗位，打包成一条微信消息发给你。

不用服务器、不用花钱、配好之后什么都不用管。

**它做三件事：**

| | |
|---|---|
| 🔍 **只报今天新增** | 昨天看过的不再出现，一分钟看完，不用在几千条存量里找新的 |
| 🎯 **只推你能投的** | 按方向 × 城市 × 届别过滤，自动排掉实习岗、和「3 年以上经验」的社招岗 |
| 🔗 **点开就能投** | 岗位名本身就是投递链接，不用再自己去官网找入口 |

**给谁用**：产品 / 运营 / 电商 / 策展 / 增长营销 / 市场公关 / 媒体内容 / 商业分析 /
人力行政 / 项目 / 客户成功——文科、商科、艺术背景的**非技术岗**求职者。
默认这 11 个方向全开，不想看的删掉一组就行。

### 接入了哪些源

**45 个源，全部直连各公司招聘官网自己在用的公开接口**（不是二手聚合站的转载）：

| 类别 | 公司 |
|------|------|
| **互联网大厂**<br>校招 + 社招 | 腾讯、字节跳动、阿里巴巴、百度、美团、京东、小红书、B站、小米、滴滴、快手、网易、拼多多、淘宝、米哈游 |
| **快消 / 零售 / 消费品牌** | 泡泡玛特、名创优品、喜茶、蒙牛、伊利、统一、青岛啤酒、维达、欧莱雅、农夫山泉、元气森林、保利发展 |
| **文化 / 艺术机构** | UCCA 尤伦斯当代艺术中心、宽创国际、凯谛思 |
| **聚合兜底** | 牛客网校招日程、OfferStar |

> **不碰 BOSS 直聘 / 智联 / 前程无忧**——它们要登录、反爬极强，且抓取违反其使用条款。
> 这是一条自觉的红线，不是能力问题。

### 每天长这样

  <img src="assets/push-preview.png" alt="微信推送效果预览" width="90%">
</p>

**什么时候能收到？** 每天早上 **7:30 前后**。

GitHub 的定时任务偶尔会延迟（这是它的老毛病，谁也管不了），所以这里设了 5 个触发点
——7:30 / 8:15 / 9:00 / 10:23 / 12:00，**谁先跑成功谁负责推送，最迟中午前一定到**，
而且**一天只会推一次**，不会重复轰炸。

如果哪天所有推送渠道都失败了，GitHub 会自动把那次运行标红并发邮件通知你，不会悄无声息。

## 二、怎么用（五分钟，不需要会写代码）

### 第 1 步 · Fork 这个仓库

点右上角 **Fork**。建议**勾上 Private**（你的求职配置属于隐私）。

Fork 完进入**你自己的**仓库 → 点 **Actions** 标签页 →
点那个绿色的 `I understand my workflows, go ahead and enable them` 把自动运行打开。

### 第 2 步 · 拿到微信推送的钥匙

我们用 [**Server酱**](https://sct.ftqq.com/) 把消息发到你微信（免费额度足够每天一条）。

1. 打开 **https://sct.ftqq.com/**
2. 点右上角登录 → **微信扫码**
3. 登录后进 **SendKey** 页面，复制那串 `SCT` 开头的密钥
4. 页面上会让你**关注「方糖」服务号**——一定要关注，不然消息发不到你微信

> ⚠️ 这串 key 等于「往你微信发消息」的权限。
> **别写进代码、别发在 issue 里、别截图发群**。下一步教你正确安放它。

### 第 3 步 · 把钥匙填进 GitHub Secrets ⭐ 最关键的一步

**这是最多人搞错的地方：钥匙不是写在代码里的，是填到 GitHub 的 Secrets 里。**

Secrets 是 GitHub 提供的加密保险箱，填进去之后连你自己都看不到明文，
运行日志里只会显示 `***`，别人 fork 你的仓库也拿不走。

点击路径（照着点就行）：

```
你的仓库
  └─ Settings（仓库设置，注意不是右上角头像里的账号设置）
       └─ 左侧边栏 Secrets and variables
            └─ Actions
                 └─ 绿色按钮 New repository secret
```

然后填两个框：

| 框 | 填什么 |
|----|--------|
| **Name** | `PUSH_KEY` ← 必须一模一样，全大写，别加空格 |
| **Secret** | 第 2 步复制的那串 SendKey |

点 **Add secret** 保存，完成。

**想让家人朋友也一起收到？** 各自去第 2 步拿自己的 SendKey，
然后用**英文逗号**连起来，填进同一个 `PUSH_KEY`：

```
SCT111111你的key,SCT222222家人的key
```

### 第 4 步 · 改成你自己的求职画像（可选，但强烈建议）

| 想改什么 | 改哪里 |
|---------|--------|
| **加自己的求职方向** | 只改 [`user_profile.py`](user_profile.py)——这是隔离的用户区，写错了也不会影响抓取、不会让每日任务崩掉 |
| 城市 / 届别 / 经验门槛 | `config.py` 里的 `TARGET_CITIES` / `TARGET_GRAD_YEARS` / `SOCIAL_MAX_EXPERIENCE_YEARS` |
| 不想看某个方向 | `config.py` 的 `KEYWORDS` 里删掉那一组 |

届别填任意年份组合都行（`[2026]`、`[2027, 2028]` 都可以），系统自动适配，明年不用改代码。

### 第 5 步 · 手动跑一次，验证能收到

**Actions** 标签页 → 左边选 **秋招雷达日报** → 右边 **Run workflow** → 绿色按钮。

约 10 分钟后微信收到推送 = 大功告成 🎉 之后每天早上自动跑，你什么都不用管。

> 如果运行被「防抢跑守卫」拦下，说明仓库里当天已经有过一次产出（比如定时任务刚跑完）。
> 这是防止重复推送的保护。想强制再跑一次，在 Run workflow 的下拉框里把 `force` 勾选上即可。
