## 一、这是什么

**一个给文科生的秋招自动岗位推送工具。**

它接入了 **45 个招聘源头**——腾讯、字节跳动、小红书、美团、泡泡玛特、喜茶、UCCA……
每天早上自动把这些公司的招聘官网跑一遍，**抓下今天新放出的岗位名字**，
从里面挑出**你能投的**，打包成一条微信消息发给你。

不用服务器、不用花钱、配好之后什么都不用管。

**它替你做三件事：**

| | |
|---|---|
| 🔍 **只报今天新增** | 昨天看过的不再出现。一分钟看完，不用在几千条存量里找哪条是新的 |
| 🎯 **只推你能投的** | 按方向 × 城市 × 届别筛选，自动排掉实习岗、和「3 年以上经验」的社招岗 |
| 🔗 **点开就能投** | 岗位名本身就是投递链接，不用再自己去官网找入口 |

**给谁用**：产品 / 运营 / 电商 / 策展 / 增长营销 / 市场公关 / 媒体内容 / 商业分析 /
人力行政 / 项目 / 客户成功——文科、商科、艺术背景的**非技术岗**求职者。
默认这 11 个方向全开，不想看的删掉一组就行。

|------|------|
| **互联网大厂**<br>校招 + 社招 | 腾讯、字节跳动、阿里巴巴、百度、美团、京东、小红书、B站、小米、滴滴、快手、网易、拼多多、淘宝、米哈游 |

### 每天长这样

  <img src="assets/push-preview.png" alt="微信推送效果预览" width="90%">

**什么时候能收到？** 每天早上 **7:30 前后**。

GitHub 的定时任务偶尔会延迟（这是它的老毛病，谁也管不了），所以这里设了 5 个触发点
——7:30 / 8:15 / 9:00 / 10:23 / 12:00，**谁先跑成功谁负责推送，最迟中午前一定到**，
而且**一天只会推一次**，不会重复轰炸。

如果哪天所有推送渠道都失败了，GitHub 会自动把那次运行标红并发邮件通知你，不会悄无声息。

## 二、怎么用

**五分钟，不需要会写代码。** 一共就三件事：把仓库复制一份 → 拿一把微信钥匙 → 把钥匙存进保险箱。

### 第 1 步 · 把这个仓库复制一份给自己

点这个页面右上角的 **Fork** 按钮，建议**勾上 Private**（你的求职配置属于隐私）。

复制完会跳到**你自己的**仓库（网址变成 `github.com/你的用户名/wenke-radar`）。
在你自己的仓库里点 **Actions** 标签页 →
点那个绿色的 `I understand my workflows, go ahead and enable them`，把自动运行打开。

### 第 2 步 · 拿一把「往你微信发消息」的钥匙

微信不允许随便一个程序给你发消息，所以要通过 [**Server酱**](https://sct.ftqq.com/) 中转一下（免费）。

1. 手机或电脑打开 **https://sct.ftqq.com/**
2. 点登录 → **微信扫码**
3. 登录后进 **SendKey** 页面，会看到一串 `SCT` 开头的字符，**点复制**
4. 同一个页面会提示你**关注「方糖」服务号**——**一定要关注**，不然消息发不进你微信
5. 关注完，在网页上点一下 **「发送测试消息」**，微信如果收到了，说明这把钥匙是通的 ✅

> ⚠️ 这串字符 = 往你微信发消息的权限。**别写进代码、别发在 issue 里、别截图发群。**

### 第 3 步 · ⭐ 拿到钥匙之后要做什么？（最关键的一步）

**一句话回答：把它填进你自己仓库的「保险箱」，填完就再也不用管它了。**

先说清楚**为什么不是写进代码**：代码是会被看到的（公开仓库任何人可见，私有仓库也可能截图外传）。
GitHub 专门准备了一个叫 **Secrets** 的加密保险箱，钥匙放进去之后，
**连你自己都看不到明文**，运行日志里只会显示 `***`，别人 fork 你的仓库也拿不走。

**照着点，30 秒搞定：**

**①** 打开**你自己**那个仓库的首页（`github.com/你的用户名/wenke-radar`）

**②** 顶部那排菜单（Code、Issues、Pull requests、Actions……）**最右边**，点 **⚙️ Settings**

> 注意：是**仓库**的 Settings，不是右上角你头像点开的那个账号设置。找错了就看不到下一步。

**③** 左侧一长条菜单往下拉，找到 **Secrets and variables**，点一下展开，选里面的 **Actions**

**④** 点页面右上角绿色按钮 **New repository secret**

**⑤** 出现两个输入框，这样填：

| 输入框 | 填什么 |
|--------|--------|
| **Name** | `PUSH_KEY` ← 直接复制这个词，全大写、不要有空格，一个字母都不能差 |
| **Secret** | 第 2 步复制的那串 `SCT` 开头的钥匙 |

**⑥** 点 **Add secret** 保存

**怎么知道成功了？** 页面会跳回列表，多出一行 `PUSH_KEY`，后面写着 `Updated now`。
你点进去也看不到内容——**这是正常的**，说明它被加密保管好了。

**然后呢？什么都不用做了。**
以后每天早上 GitHub 自动运行的时候，会自己从保险箱里取出这把钥匙，
用它把今天的新岗位发到你微信。你不需要再碰它。

**想让家人朋友也一起收到？** 让他们各自照第 2 步拿自己的钥匙，
然后用**英文逗号**连起来，一起填进同一个 `PUSH_KEY`（一个逗号隔一个，中间别加空格）：

```
SCT111111你的钥匙,SCT222222家人的钥匙
```

### 第 4 步 · 改成你自己的求职画像（可选，但建议）

| 想改什么 | 改哪个文件 |
|---------|-----------|
| **加自己的求职方向** | 只改 [`user_profile.py`](user_profile.py)——这是隔离的用户区，写错了也不会影响抓取、不会让每日任务崩掉 |
| 想看哪些城市 | `config.py` 里的 `TARGET_CITIES` |
| 哪几届 / 能接受几年经验 | `config.py` 里的 `TARGET_GRAD_YEARS` / `SOCIAL_MAX_EXPERIENCE_YEARS` |
| 不想看某个方向 | `config.py` 的 `KEYWORDS` 里删掉那一组 |

届别填任意年份组合都行（`[2026]`、`[2027, 2028]` 都可以），系统自动适配，明年不用改代码。

### 第 5 步 · 跑一次，验证能收到

**Actions** 标签页 → 左边选 **秋招雷达日报** → 右边 **Run workflow** → 点绿色按钮。

约 10 分钟后微信收到推送 = 大功告成 🎉 之后每天早上自动跑，你什么都不用管。

<details>
<summary><b>没收到推送？照这三步排查</b></summary>

1. **微信有没有关注「方糖」服务号？**
   回到 https://sct.ftqq.com/ 点「发送测试消息」，微信收不到就是这一步没做好。
2. **Secrets 里的名字是不是一字不差？**
   必须是 `PUSH_KEY`，全大写、无空格。写成 `push_key` 或 `PUSHKEY` 都不行。
3. **那次运行是不是失败了（红色叉）？**
   Actions 标签页里点进那次运行，能看到具体报错。全部推送渠道失败时，
   GitHub 也会自动给你发一封邮件提醒。

如果运行被「防抢跑守卫」拦下，说明仓库里当天已经产出过一次日报了（这是防止重复推送的保护）。
想强制再跑一次，在 Run workflow 的下拉框里把 `force` 勾上即可。
</details>

<details>
<summary><b>想在自己电脑上跑？（可选）</b></summary>

```bash
pip install -r requirements.txt

# Windows 必须带 PYTHONUTF8=1，否则中文会报错
PYTHONUTF8=1 python main.py --full   # 首次：全量建库
PYTHONUTF8=1 python main.py          # 之后：每日增量
PYTHONUTF8=1 python -m pytest tests/ -q   # 跑测试（230 个）
```
</details>

<details>
<summary><b>想加一个新公司的招聘源？</b></summary>

1. 这家公司用**北森 / 飞书 / 百库 / Moka** 招聘系统？→ 加个子类 + 一段配置，不用写解析代码
2. 是标准 JSON 接口？→ 在 `config.GENERIC_SOURCES` 写一段声明，零代码
3. 全新平台 → 在 `scrapers/` 新建模块继承 `BaseScraper`，然后在三处注册

改完跑 `pytest`——37 个源存了真实响应样本做契约测试，改坏了 CI 会拦住你。
欢迎提 PR 贡献新的源，尤其是文科生对口的文化 / 出版 / 教育 / 咨询类机构。
</details>
