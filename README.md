## 一、这是什么

**一个给文科生的秋招自动岗位推送工具。**

它接入了 **45 个招聘源头**——腾讯、字节跳动、小红书、美团、泡泡玛特、喜茶、UCCA……
每天早上自动把这些公司的招聘官网跑一遍，**抓下今天新放出的岗位名字**，
从里面挑出**你能投的**，打包成一条微信消息发给你。

不用服务器、不用花钱、配好之后什么都不用管。

**它替你做三件事：**

| | |
|---|---|
| 🔍 **只报今天新增** | 昨天看过的不再出现。一分钟看完，不用在几千条存量里找哪条是新的 |
| 🎯 **只推你能投的** | 按方向 × 城市 × 届别筛选，自动排掉实习岗、和「3 年以上经验」的社招岗 |
| 🔗 **点开就能投** | 岗位名本身就是投递链接，不用再自己去官网找入口 |

**给谁用**：产品 / 运营 / 电商 / 策展 / 增长营销 / 市场公关 / 媒体内容 / 商业分析 /
人力行政 / 项目 / 客户成功——文科、商科、艺术背景的**非技术岗**求职者。
默认这 11 个方向全开，不想看的删掉一组就行。

### 每天长这样

**什么时候能收到？** 每天早上 **7:30 前后**。

GitHub 的定时任务偶尔会延迟（这是它的老毛病，谁也管不了），所以这里设了 5 个触发点
——7:30 / 8:15 / 9:00 / 10:23 / 12:00，**谁先跑成功谁负责推送，最迟中午前一定到**，
而且**一天只会推一次**，不会重复轰炸。

如果哪天所有推送渠道都失败了，GitHub 会自动把那次运行标红并发邮件通知你，不会悄无声息。

## 二、怎么用

**五分钟，不需要会写代码，也不需要懂 GitHub。**
一共就三件事：**把仓库复制一份 → 拿一把微信钥匙 → 把钥匙存进保险箱。**

> 🤖 **完全没用过 GitHub、看着发怵？**
> 跳到本节最后的 [「把这段话复制给 AI」](#-卡住了把这段话复制给-ai)，
> 让 AI 一步步带你做，比自己啃文档快得多。

### 第 0 步 · 没有 GitHub 账号的话，先注册一个

打开 **https://github.com/signup**，用邮箱注册，免费。
（GitHub 是全球程序员放代码的地方，这个工具就跑在它上面，不花钱。）

### 第 1 步 · 把这个仓库复制一份给自己

**为什么要复制？** 因为你要往里面填你自己的钥匙、改你自己的求职方向——
在别人的仓库里你没有权限，必须有一份属于你的。GitHub 管这个叫 **Fork**。

**怎么做：** 点这个页面**右上角**的 **Fork** 按钮 → 下一页建议**勾上 Private**（你的求职配置属于隐私）
→ 点 **Create fork**。

**成功的标志：** 页面自动跳转，浏览器地址栏变成 `github.com/`**`你的用户名`**`/wenke-radar`。

> ⚠️ 后面所有操作都要在**你自己这个仓库**里做。
> 如果地址里还是 `onism1767-creator`，说明你还在原作者的仓库，那里你改不了任何东西。
> 迷路了就点右上角你的头像 → **Your repositories** → 点 `wenke-radar` 回来。

**接着把自动运行打开：** 在你自己的仓库里点上方的 **Actions** 标签页，
会看到一个提示页，点那个绿色按钮 `I understand my workflows, go ahead and enable them`。

### 第 2 步 · 拿一把「往你微信发消息」的钥匙

微信不允许随便一个程序给你发消息，所以要通过 [**Server酱**](https://sct.ftqq.com/) 中转一下（免费）。

1. 手机或电脑打开 **https://sct.ftqq.com/**
2. 点登录 → **微信扫码**（用你想接收消息的那个微信扫）
3. 登录后进 **SendKey** 页面，会看到一串 `SCT` 开头的长字符，**点复制**
   → 先把它粘贴到手机备忘录/电脑记事本里存着，下一步要用
4. 同一个页面会提示你**关注「方糖」服务号**——**一定要关注**，不然消息发不进你微信
5. 关注完，在网页上点一下 **「发送测试消息」**，微信如果收到了，说明这把钥匙是通的 ✅
   （**这一步很值得做**：先确认微信这端是通的，后面出问题就能排除掉一半原因）

> ⚠️ 这串字符 = 往你微信发消息的权限。**别写进代码、别发在 issue 里、别截图发群。**

### 第 3 步 · ⭐ 拿到钥匙之后要做什么？（最关键的一步）

**先给结论：把这串钥匙，粘贴到你自己仓库的一个叫 Secrets 的地方，取名叫 `PUSH_KEY`，保存。
做完这件事，你就再也不用碰它了。**

**为什么不是直接写在代码里？** 代码是会被看见的（公开仓库谁都能看，私有仓库也可能被截图外传）。
GitHub 专门准备了一个加密的地方叫 **Secrets**（可以理解成保险箱）：
钥匙放进去之后**连你自己都看不到明文**，运行日志里只显示 `***`，别人 fork 你的仓库也拿不走。

**下面这张图是四步各自长什么样，照着找就行：**

<p align="center">
  <img src="assets/secrets-guide.png" alt="把钥匙填进 GitHub Secrets 的四步图解" width="100%">
</p>

**文字版（配合上图看）：**

**①  打开你自己的仓库，点最右边的 Settings**

- 在哪：仓库名下面有一排横着的菜单——`Code`　`Issues`　`Pull requests`　`Actions`　`Insights`　`Settings`
- 点哪个：**最右边**那个带小齿轮 ⚙️ 的 **Settings**
- ⚠️ 最容易走错的地方：**别点右上角你头像里的 Settings**，那是账号设置，里面根本没有下一步要找的东西

**②  在左边的竖排菜单里，找到 Secrets and variables**

- 点进 Settings 后，页面**左侧**是一长条竖着的菜单（General、Collaborators、Branches……）
- 往下拉，找到 **Secrets and variables**，点一下
- 点完它下面会**展开**出几个子项，选第一个：**Actions**

**③  点右上角的绿色按钮 New repository secret**

- 现在页面上应该写着 `Repository secrets`，下面是空的（还没有任何钥匙）
- 右上角有个**绿色**按钮，上面写 **New repository secret**，点它

**④  填两个输入框，然后保存**

| 输入框 | 填什么 |
|--------|--------|
| 上面的 **Name** | `PUSH_KEY` ← **直接复制这个词**。全大写、中间是下划线不是减号、前后不能有空格，**一个字母都不能差** |
| 下面的 **Secret** | 第 2 步复制的那串 `SCT` 开头的钥匙，直接粘贴进去 |

填完点下面的绿色按钮 **Add secret**。

**✅ 怎么知道成功了？**
页面会跳回列表，多出一行 `PUSH_KEY`，右边写着 `Updated now`（如上图最下方那样）。
**你点进去看不到里面的内容——这是正常的**，不是没存上，是它被加密保管了。

**🎉 然后呢？什么都不用做了。**
以后每天早上，程序自动运行时会自己去这个保险箱取钥匙，用它把新岗位发到你微信。
这一步是一次性的，做完就永远不用再管。

**想让家人朋友也一起收到？** 让他们各自照第 2 步拿自己的钥匙，
然后用**英文逗号**连起来，一起填进同一个 `PUSH_KEY`（一个逗号隔一个，中间别加空格）：

```
SCT111111你的钥匙,SCT222222朋友的钥匙
```

#### 🤖 卡住了？把这段话复制给 AI

不管哪一步卡住，**把下面这段话整段复制**，发给任意 AI 助手（ChatGPT / Claude / 豆包 / 通义 / DeepSeek 都行），
它会一步步带你做。**注意：千万别把你的钥匙（SCT 开头那串）发给 AI。**

```text
我是 GitHub 零基础用户，正在配置一个开源项目「不绝望的文科生秋招」
（github.com/onism1767-creator/wenke-radar）。它是一个每天早上把新招聘岗位
推送到我微信的小工具。

我现在要做的事：我已经从 Server酱（sct.ftqq.com）拿到了一串 SCT 开头的 SendKey，
需要把它填进我自己 Fork 的那个 GitHub 仓库里，位置是
Settings → Secrets and variables → Actions → New repository secret，
名字必须叫 PUSH_KEY。

请你用最啰嗦、最零基础的方式，一步一步告诉我该点哪里。要求：
1. 每一步都描述"我在屏幕上应该看到什么"（按钮什么颜色、在页面哪个位置、写着什么英文）
2. 一次只讲一步，讲完等我回复"好了"再讲下一步
3. 如果我说看到的画面和你描述的不一样，先问我具体看到了什么，别急着往下讲
4. 我看不懂英文界面，请把每个英文单词的意思也解释一下

另外提醒我一句：过程中不要把 SendKey 本身发给你。
```

如果是**已经填完了但收不到推送**，把这段发给 AI：

```text

它通过 Server酱 往我微信推送招聘岗位。我已经把 SendKey 填进仓库的
Settings → Secrets and variables → Actions 里，名字是 PUSH_KEY，
但微信收不到消息。

请一步步帮我排查，每次只问我一个问题、等我回答再继续。我知道的线索：
（把你的情况写在这里，比如：GitHub Actions 里那次运行是绿色的还是红色的、
Server酱官网点"发送测试消息"微信能不能收到、有没有关注「方糖」服务号）
```

### 第 4 步 · 改成你自己的求职画像（可选，但建议）

| 想改什么 | 改哪个文件 |
|---------|-----------|
| **加自己的求职方向** | 只改 [`user_profile.py`](user_profile.py)——这是隔离的用户区，写错了也不会影响抓取、不会让每日任务崩掉 |
| 想看哪些城市 | `config.py` 里的 `TARGET_CITIES` |
| 哪几届 / 能接受几年经验 | `config.py` 里的 `TARGET_GRAD_YEARS` / `SOCIAL_MAX_EXPERIENCE_YEARS` |
| 不想看某个方向 | `config.py` 的 `KEYWORDS` 里删掉那一组 |

届别填任意年份组合都行（`[2026]`、`[2027, 2028]` 都可以），系统自动适配，明年不用改代码。

### 第 5 步 · 跑一次，验证能收到

**Actions** 标签页 → 左边选 **秋招雷达日报** → 右边 **Run workflow** → 点绿色按钮。

约 10 分钟后微信收到推送 = 大功告成 🎉 之后每天早上自动跑，你什么都不用管。

<details>
<summary><b>没收到推送？照这三步排查</b></summary>

1. **微信有没有关注「方糖」服务号？**
   回到 https://sct.ftqq.com/ 点「发送测试消息」，微信收不到就是这一步没做好。
2. **Secrets 里的名字是不是一字不差？**
   必须是 `PUSH_KEY`，全大写、无空格。写成 `push_key` 或 `PUSHKEY` 都不行。
3. **那次运行是不是失败了（红色叉）？**
   Actions 标签页里点进那次运行，能看到具体报错。全部推送渠道失败时，
   GitHub 也会自动给你发一封邮件提醒。

如果运行被「防抢跑守卫」拦下，说明仓库里当天已经产出过一次日报了（这是防止重复推送的保护）。
想强制再跑一次，在 Run workflow 的下拉框里把 `force` 勾上即可。
</details>

<details>
<summary><b>想加一个新公司的招聘源？</b></summary>

1. 这家公司用**北森 / 飞书 / 百库 / Moka** 招聘系统？→ 加个子类 + 一段配置，不用写解析代码
